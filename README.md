# Flux Weddings — Luxury Concept

A premium editorial redesign concept for Flux Weddings, built with React, TypeScript and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Design direction

The concept shifts Flux from a conventional wedding-photography presentation toward an editorial luxury studio: restrained typography, large-format imagery, generous whitespace, cinematic pacing and a more selective sales narrative.

> Prototype note: the current build uses temporary Unsplash photography as visual placeholders. Replace these with licensed/original Flux Weddings imagery before production deployment.
